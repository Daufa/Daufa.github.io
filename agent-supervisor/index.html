Independent Project

Agent Supervisor

Coordinating AI coding agents so I don't have to.

Experimental alpha  ·  built and tested on macOS

The Problem

Two agents, no coordination.

Using two coding agents together meant copying responses between terminals by hand. Asking one to check the other's work. Losing track of what was actually tested.

What It Does

It automates the handoff.

Agent Supervisor starts an agent on an explicit task, validates its response, records the result, and hands the work to its peer, with clear stopping conditions built in.

How It Works

It's been running against my LLM Council project, the workspace that surfaced the original coordination problem.

1A task on LLM Council: an explicit, scoped ask
2The Python supervisor takes the task and the workspace
3Claude Code makes the change
4Posts a validated JSON handoff to the shared log
5Codex reviews the change and runs the tests
6Claude verifies the unchanged result
7Mutual completion, or a bounded stop
Built With

Just the Python standard library.

No third-party open source packages, so nothing extra to license.

It runs two existing developer tools, the Claude Code CLI and the Codex CLI, as separate processes. Their source code isn't part of this project.

An independent project. Not affiliated with Anthropic or OpenAI.

Verified Before Trusted

Tested offline. Run live.

It's been checked with offline tests and a full live run end to end. The specific numbers and trial history are documented at github.com/Daufa/agent-supervisor.
