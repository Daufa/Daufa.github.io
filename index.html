Agent Supervisor

A Python supervisor that coordinates Claude Code and Codex through bounded implementation and peer-review cycles.

Automates the handoff between two coding agents: one implements, the other reviews, with validated JSON messages, SHA-256 project fingerprints that invalidate a completion claim if the codebase changed since it was made, and atomic checkpoints with per-turn timeouts so a stuck run fails safely instead of hanging. Backed by an offline test suite, plus one live run where it caught and fixed a real bug in its own diagnostic-write path: implement, review, verify, done, no manual relay. Early days: that's one clean cycle, not a track record.

Built at Romet  ·  04 / 07

Account Owner AI Digest

Daily AI-generated case digest that adds an urgency read the age-based rules alone can't provide, delivered automatically, no chatbot required.

Two Copilot Studio prompts wired into a scheduled Power Automate flow: one reads a flagged case's notes and calls out urgency signals a pure age-based triage system misses (deadlines, frustration, repeated failures), the other turns each owner's flagged cases into a short, friendly digest capped at 150 words. The flow filters the triage workbook down to Overdue and Critical cases, skips owners with nothing flagged so there's no noise, and posts straight to Teams or email every morning without anyone asking it to.
